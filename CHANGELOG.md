# Changelog

Newest version first. After every install the installer shows all versions of the current big
release (e.g. everything since 5.0.0) and marks the ones that are new for you.
Format: a `## <version>` line, then one `- ` bullet per change.

## 5.1.2
- Changelog: every install shows all changes since 5.0.0, the new ones marked (new)
- LAN: less lag for friends on busy maps like $2000$ (higher network limits)

## 5.1.1
- Updates from GitHub: double-click update.bat to get the newest version
- The installer refuses a game that was never started (start it once first)

## 5.1.0
- Undead script now works at 10 HP or less (was 5)
- Hostage "και νενενε" sounds are louder
- O hides / shows the stats and the key list on the left
- Security cameras: clicks should no longer stop switching cameras
- Spray logo fixed (Defend JulMaYa instead of the default one)

## 5.0.1
- New life steal script: heal 3% of the damage you deal (amx_lifesteal_pct)
- All players can use the script hotkeys, not only the host
- Security cameras: no more stuck player name in the middle of the screen
- Scripts cleaned up: one stats box, the key list right below it

## 5.0.0
- Easy install / uninstall (install.bat, uninstall.bat), your own settings are kept
- Stats: headshots fixed to match the scoreboard, headshot percentage added
- All stats moved to the left of the screen
- New undead script: stay at 5 HP for 3 seconds and you can't die this round
- Security cameras on minitaly when you're dead
- New "fire in the hole" sound and hostage sounds
- Radio: new phrase "δαγκωμα με τα ουλα"
- $2000$: no more lag from the bots, broken sky fixed

## 4.0.0
- Greek menus, radio, taunts and loading texts, our intro and background
- New weapon models and sounds (m4a1, mp5, awp, deagle, usp, knife, bombs)
- New player models for both teams
- Our spray logo
- Scripts: kill taunts, enemies alive, headshot and HE stats, wallhack for the last enemies
- New maps: apartments, minitaly, $2000$, de_beishan and more
